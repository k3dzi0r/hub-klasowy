# Relaks — pliki i źródła

## Jak dodać lub zmienić

Wrzuć plik do odpowiedniego folderu — aplikacja sama go znajdzie (przy `npm run dev` od razu, w wersji zbudowanej po `npm run build`).

| Folder | Co tu wrzucać |
| --- | --- |
| `obrazy/` | `.jpg`, `.png`, `.webp` — najlepiej poziome 16:9 |
| `muzyka/` | `.mp3`, `.m4a`, `.ogg`, `.wav` — utwory grają po kolei, w kółko |
| `natura/` | `.mp3`, `.m4a`, `.ogg`, `.wav` — nagranie powtarza się bez końca |

- Tytuł bierze się z nazwy pliku: `03 Deszcz na dachu.mp3` → „Deszcz na dachu”, `spokojne-morze.jpg` → „Spokojne morze”.
- Liczba na początku ustala kolejność na liście i nie jest wyświetlana.
- Żeby usunąć pozycję, usuń plik.
